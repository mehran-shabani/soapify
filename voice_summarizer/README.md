# خلاصه‌ساز هوشمند سخنرانی

این پروژه یک سرویس Django برای رونویسی و خلاصه‌سازی هوشمند فایل‌های صوتی سخنرانی است که با استفاده از OpenAI پیاده‌سازی شده است.

## پیش‌نیازها
- Python 3.10 یا جدیدتر

## راه‌اندازی سریع
1. ایجاد و فعال‌سازی محیط مجازی:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # در ویندوز: .venv\\Scripts\\activate
   ```
2. نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```
   برای اجرای تست‌ها و توسعهٔ محلی، وابستگی‌های تکمیلی را نیز نصب کنید:
   ```bash
   pip install -r requirements.dev.txt
   ```
3. ساخت فایل تنظیمات محیطی:
   ```bash
   cp .env.example .env
   ```
4. اجرای مهاجرت‌های پایگاه‌داده:
   ```bash
   python manage.py migrate
   ```
5. اجرای سرور توسعه:
   ```bash
   python manage.py runserver
   ```
6. مشاهدهٔ برنامه در آدرس [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## اجرای تست‌ها
- برای اجرای مجموعه تست‌ها از Pytest استفاده کنید:
  ```bash
  pytest -q
  ```

## پیکربندی OpenAI
- مقدار `OPENAI_API_KEY` را با کلید معتبر جایگزین کنید.
- مقدار `OPENAI_BASE_URL` اختیاری است؛ اگر نیاز به سرور سازگار با OpenAI دارید این مقدار را تعیین کنید، در غیر این صورت خالی بماند تا مقدار پیش‌فرض SDK استفاده شود.
- مقادیر `OPENAI_TRANSCRIBE_MODEL` و `OPENAI_SUMMARY_MODEL` را بر اساس مدل‌های سازگار مورد نظر خود تنظیم کنید.

## پوشهٔ رسانه
- دایرکتوری `media/` برای نگه‌داری موقت فایل‌های بارگذاری‌شده استفاده می‌شود و پس از پردازش فایل حذف خواهد شد.

## رفع اشکال متداول
- **کلید نامعتبر یا تنظیم‌نشده:** در صورت مشاهدهٔ پیام «OPENAI_API_KEY تنظیم نشده است.» مقدار را در فایل `.env` تصحیح کنید.
- **ارائه‌دهندهٔ سازگار:** در صورت نیاز به استفاده از درگاه سازگار با OpenAI آدرس پایه را در `OPENAI_BASE_URL` قرار دهید؛ اگر خالی بماند از مقدار پیش‌فرض SDK استفاده می‌شود.
- **محدودیت فایل:** تنها پسوندهای mp3، wav، m4a، aac، ogg، flac و webm با حجم حداکثر ۱۰ مگابایت پذیرفته می‌شوند.

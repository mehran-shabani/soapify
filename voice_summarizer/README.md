# خلاصه‌ساز هوشمند سخنرانی

این مخزن اسکلت اولیهٔ پروژهٔ «خلاصه‌ساز هوشمند سخنرانی» بر پایهٔ Django است. در این مرحله تنها ساختار اولیه و صفحات سادهٔ بارگذاری پیاده‌سازی شده‌اند و منطق پردازش صوت در گام بعدی افزوده خواهد شد.

## پیش‌نیازها
- Python 3.10 یا جدیدتر

## راه‌اندازی سریع
1. ایجاد و فعال‌سازی محیط مجازی:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # در ویندوز: .venv\\Scripts\\activate
   ```
2. نصب وابستگی‌ها:
   ```bash
   pip install -r requirements.txt
   ```
3. ساخت فایل تنظیمات محیطی:
   ```bash
   cp .env.example .env
   ```
4. اجرای مهاجرت‌های پایگاه‌داده:
   ```bash
   python manage.py migrate
   ```
5. اجرای سرور توسعه:
   ```bash
   python manage.py runserver
   ```
6. مشاهدهٔ برنامه در آدرس [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## پیکربندی OpenAI
- مقدار `OPENAI_API_KEY` را با کلید معتبر جایگزین کنید.
- مقدار `OPENAI_BASE_URL` اختیاری است؛ اگر نیاز به سرور سازگار با OpenAI دارید این مقدار را تعیین کنید، در غیر این صورت خالی بماند تا مقدار پیش‌فرض SDK استفاده شود.
- مقادیر `OPENAI_TRANSCRIBE_MODEL` و `OPENAI_SUMMARY_MODEL` قابل ویرایش هستند و در مراحل بعدی برای پردازش استفاده می‌شوند.

## توضیحات
- دایرکتوری `media/` برای نگه‌داری موقت فایل‌های بارگذاری‌شده در نظر گرفته شده است.
- منطق تماس با OpenAI در این مرحله پیاده‌سازی نشده و در گام بعدی افزوده می‌شود.
